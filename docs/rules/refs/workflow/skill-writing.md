# スキル (SKILL.md) の書き方

`.claude/skills/*/SKILL.md` を書く・直すときの方針。docs/rules を書くときの [rule.md](./rule.md) と同じ「**AI が既に知っていること・自明なことは書かない**」原則を、skill にも適用する。

## 非自明な要点だけ書く

各行を「**Claude が知らない / 迷う情報か?**」で取捨する。

- 書く: 具体的な CLI コマンド・エスケープの確定形、実地で発見したヒューリスティック、固有の安全則 / ポリシー、分岐の意味。
- 削る: コードの探し方・検証の進め方といった Claude が自分で判断できる一般手順、他節と重複する定義。

冗長な手続き narration は Claude が元々できることで、読む量を増やして要点を埋もれさせるだけ。

## 例外: 人間向けランブック

人間が手順どおり辿るランブック(例: `setup.md`)は対象が人間なので、手順を明示的に残してよい。
