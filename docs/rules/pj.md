# プロジェクト固有ルール

このファイルは本プロジェクト固有のルールのインデックスである。
テンプレート由来の共通ルールは [general.md](./general.md) を参照する。

各項目の「参照条件」に該当する作業を行う際、対応するリンク先のドキュメントを読み込み、その内容に従う。
ルールを追加する際は [general.md](./general.md) と同様に「タイトル / 参照条件 / リンク」のセット形式で並べ、本体ドキュメントは `refs/` 配下に作成する。書き方の詳細は [refs/workflow/rule.md](./refs/workflow/rule.md) に従う。
