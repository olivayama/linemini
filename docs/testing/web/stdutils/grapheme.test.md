# grapheme

- 空文字は長さ 0 / 空配列
- null は長さ 0 / 空配列 (実行時ガード)
- ASCII・日本語は 1 文字ずつ数える
- 単体絵文字 (サロゲートペア) を 1 文字として数える
- 異体字セレクタ付き絵文字 (❤️) を 1 文字として数える
- 国旗 (Regional Indicator のペア) を 1 文字として数える
- 肌の色修飾子付き絵文字を 1 文字として数える
- ZWJ 連結の顔絵文字を 1 文字として数える (回帰防止)
- ZWJ 絵文字 5 個 + 文字列を正しく数える (5×2=10 にならない)
- splitGraphemes は書記素単位で分割する
