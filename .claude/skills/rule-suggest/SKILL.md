# rule-suggest (会話からルール/スキル化を提案)

## トリガー

- `/rule-suggest` - 今の会話を対象
- `/rule-suggest <条件>` - 過去の会話も対象(トランスクリプトは `~/.claude/projects/` の JSONL。条件はトピック・パス・期間など。条件に合うセッションを探す)

## 実行手順

1. 対象から候補を拾う: 繰り返した指示・好み・手順・ハマりどころ
2. 宛先(下記)を判定。既存のルール/スキルと重複・矛盾するものは除く
3. 推奨 / 任意 / 見送り に分け、元の根拠と判定理由を添える。推奨には宛先パスと本文ドラフトも

## 宛先

- 個人ルール(全PJ共通) → `~/.claude/CLAUDE.md`
- 個人スキル(全PJ共通) → `~/.claude/skills/<name>/SKILL.md`
- プロジェクトのルール/スキル → そのプロジェクトの書き方規約に従う

## 制約

- 提案までを行い、ルール/スキルの作成はしない
- ドラフトは「AI が既に知っていることは書かない」原則に従い簡素に
