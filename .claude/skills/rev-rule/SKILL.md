# rev-rule (レビュー指摘のルール化提案)

## トリガー

- `/rev-rule <PR URL>` - PR の全レビュー指摘を対象
- `/rev-rule <PR URL> <条件>` - 条件に合う指摘のみ対象

## 実行手順

1. `docs/rules/refs/workflow/rule.md` を読み、ルールの採否・書き方の基準を把握する
2. PR 情報と既存の指摘・コメントを、解決済みスレッドも含めて全て読んで文脈を把握する
3. 条件指定時は、ルール化の対象を条件に合う指摘へ絞る
4. 関連する既存ルールを読み、重複・矛盾を避ける
5. 各指摘を 推奨 / 任意 / 見送り に分け、1 件ごとに元指摘と判定理由を添える。推奨にはさらに「追記先ファイル・index 登録・本文ドラフト」を添える

## 制約

- **PR 情報・コメントの取得は GitHub MCP を使う**（`gh` コマンドは使わない）
- 提案までを行い、ルールの追記はしない
