# rev-file (指定ファイルの差分解説 + レビュー)

## トリガー

- `/rev-file <path...>` - 現ブランチに紐づく PR を対象
- `/rev-file <PR URL> <path...>` - PR を明示

## 前提条件

以下を確認する。満たさない場合は作業を止めてユーザーに確認する。

- 引数で対象パス（ファイルまたはディレクトリ）が 1 つ以上渡されている

## 実行手順

1. `.claude/docs/rev/README.md` を読む
2. PR 情報と既存の指摘・コメントを、解決済みスレッドも含めて全て読んで文脈を把握する
3. PR の base / head SHA を取得し、引数のパスだけの差分を取る：`git diff <base sha>...<head sha> -- <path...>`
4. ローカルコードを確認してレビュー
5. ファイルごとに、次の順で出力する：
   1. **差分の解説**：hunk(差分の塊)ごとに「何が・なぜ変わったか」を順に説明する（import 文のみの差分は除外）
   2. **レビュー指摘**：README の「指摘の構成要素」に沿ってリスト化（既存指摘と重複するものは除外）

## 制約

- **レビューコメントの投稿は行わない**
