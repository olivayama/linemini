# rev-check (指摘修正の確認・返信)

## トリガー

- `/rev-check <PR URL>`

## 実行手順

1. `.claude/docs/rev/README.md` を読む
2. PR 情報と既存の指摘・コメントを、解決済みスレッドも含めて全て読んで文脈を把握する
3. 返信対象は**未解決かつ自分（認証ユーザー）が起点のスレッド**のみ
4. 対象の指摘ごとに、指摘が解決されているか・修正に新たな問題がないかをローカルコードで確認してレビュー
5. 返信案を作成
6. 各指摘スレッドへの返信として投稿
7. 解決済みと確認したスレッドを Resolve する
8. 投稿した各返信コメントのリンク・解決済み／未解決・投稿した返信の全文を、元の指摘コメントの投稿日時の古い順に報告する

## 制約

- **全体コメントは投稿しない**（各指摘スレッドへの返信のみ投稿する）
