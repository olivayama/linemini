# rev-post (レビューコメント投稿)

## トリガー

- `/rev-post` - 直前に議論した指摘事項を投稿
- `/rev-post ◯◯について` - 特定の指摘事項を投稿
- `/rev-post 全部` - `/rev` で洗い出した全指摘事項を投稿
- `/rev-post [対象] -y` - 確認なしで即投稿（対象指定と併用可）

## 前提条件

以下を確認する。満たさない場合は作業を止めてユーザーに確認する。

- チャット履歴に PR URL が含まれている

## 実行手順

1. `.claude/docs/rev/README.md` を読む
2. 対象の指摘事項をローカルコードで確認
3. レビューコメント案を README の「指摘の構成要素」に沿って作成：
   - コメント案の全文をテキストで提示し、同じメッセージ内で承認を求める（AskUserQuestion は使わない。`-y` 指定時は提示のみ行い、承認を求めない）
4. 承認後（`-y` 指定時は即時）にレビューコメントとして投稿

## 制約

- **レビュー全体のサマリー（review の body）は投稿しない**（個別の行コメントのみ投稿する）
